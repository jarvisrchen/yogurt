yogurt design mockups

Three design systems from Refero Styles applied to all five yogurt screens: onboarding, Library, live meeting, post-meeting, Settings. Same layout and copy in every set so only the system changes. Branch design-mockups.

Granola

Field notes on warm parchment. Serif editorial headlines, humanist UI face, hairline rules, a single olive accent.

Voicenotes

Cream-paper notebook with a single inkwell. Oversized Instrument Serif over whisper-quiet Inter; everything neutral except one green check.

Whimsical

Deep plum ink on lavender mist. A creative-studio notebook that thinks it is a technical whiteboard; bold geometric display, violet pill links.

  • Granola is the source yogurt already borrows its UX from; this set shows what fully adopting its system looks like, olive accent included.
  • Voicenotes is the nearest product neighbour (voice capture to notes): near-monochrome, one green status colour, big serif.
  • Whimsical pushes the existing blueberry direction further into plum and lavender, with heavier radii and real shadows.
