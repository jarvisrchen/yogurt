Live model switch

Click the LLM pill in a live meeting's header to pick which configured provider runs the live recap and the Enhance at End. Drawn with the app's tokens from web/src/index.css and the class strings from MeetingMetaPills.tsx and LabelPicker.tsx.

  • Picking a row activates that provider, the same call Settings makes. It also becomes the default for later meetings.
  • The next recap tick and the Enhance at End use the new model. A recap call already in flight finishes on the old one.
  • The menu lists configured providers only. Adding one or changing a provider's model stays in Settings.
  • Once a meeting is enhanced, the pill records what enhanced it and stays read-only.
