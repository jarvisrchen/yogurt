The one to confirm

6 · Do not build
Thirty-odd things that sounded good and were rejected, with the reason
  • A yogurt task, dev or release subcommand in the product binary: dev orchestration belongs in scripts/; ctl is different because it speaks HTTP to a running server.
  • Auto-starting just dev or a cargo build inside just start: an invisible build in a tree is the hazard AGENTS.md describes.
  • A shared CARGO_TARGET_DIR, sccache, or an APFS clone: the cold build is 35 seconds.
  • --json on the dev scripts before something parses it; one stable line per step is cheaper for an agent reading a terminal.
  • gh pr merge --auto or required status checks: docs-only PRs never report a check and would never merge.
  • A PR template: ignored whenever --body is passed, which is always.
  • A merge-on-red flag on land; land pulling the shared checkout; land removing a dirty worktree.
  • A persistent YOGURT_OWN_MAIN export: every agent spawned from that shell inherits it.
  • A Claude Code hook for commit rules: covers one agent; the git hooks cover every agent that uses git.
  • Release-profile builds on every PR, a bot that bumps and tags on main, version-from-tag at build time, an LLM-written log narrative, a local state file for ship, rewriting the release skill before the script exists.
  • A TOON serializer; ctl eval in the binary; ctl provider key set; pid in /api/health; a server-written port registry; a per-worktree keys.json; writing fixtures into SQLite from ctl.
  • A weekly LLM audit of AGENTS.md: every drift in the history is a string-existence failure a grep catches; the one exception was wrong when written.
  • A live-server docs test, a Rust drift test importing clap (no lib target), per-feature Feature Map files, synthetic audio injection at /start, any cloud macOS or Linux build, a markdownlint pass, an em-dash check over code comments (5,883 hits), splitting ARCHITECTURE.md.
