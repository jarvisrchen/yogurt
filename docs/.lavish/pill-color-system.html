What should the pill colors mean?

Right now the STT pill and the LLM pill both use blueberry, for two different reasons. Picking one rule for the whole row makes each pill readable at a glance instead of decorative.

Where we are

Today's row

Weekly sync with Design

Aug 28 · 1:08 PM 47 min Local · small.en MiniMax-M3
  • Blueberry is overloaded. On the STT pill it means "went to the cloud". On the LLM pill it means "AI touched this". Same color, two rules.
  • Cloud STT + LLM renders as two identical blue pills side by side, so the row reads as one blob.
  • It's the loudest thing in the row - brand blue is otherwise reserved for buttons and the transcript. "It got enhanced" is the normal case, not news. MeetingCard.tsx already states this rule for the sibling flag: "Tagging the normal enhanced case would be noise."
  • A local LLM reads as cloud. yogurt-llm/src/lib.rs explicitly supports Ollama and LM Studio on localhost - today they get the same blue as an API provider, so the row misreports the one fact yogurt actually promises.

The decision

Seven rules the color could follow

A through C are the original three: one rule each, applied to both pills. D through G add combinations - two-axis rules (D, E), reframed meanings (F), and pair-aware rules (G). The icon always carries the stage (drive / cloud / sparkles), so color is free to carry something else.

Option A

Color = locality

Green stayed on this Mac, blue left it. Same rule for STT and LLM, so scanning the row answers "did anything leave?" without reading a word.

Local · small.en llama3.1 Cloud · nova-3 MiniMax-M3

Cost: needs the backend to stamp LLM locality (host of base_url). A cloud+cloud meeting is still two blue pills - but now that's true information.

Option B

Color = stage

Matcha is always transcription, blueberry is always enhancement. Fastest to tell the two pills apart; local/cloud demotes to the icon.

Local · small.en Cloud · nova-3 MiniMax-M3

Cost: throws away the privacy signal to color-code something the icon already says. Cheapest diff, weakest meaning - green would now mean "audio left the Mac" half the time.

Option C · recommended

Quiet, color = good news

Metadata is quiet by default. Color is spent only on the two things worth noticing: matcha = it stayed on this Mac, strawberry = something's off. Cloud is the unremarkable default and gets the same neutral chrome as the date.

Local · small.en Cloud · nova-3 MiniMax-M3 not enhanced

Cost: cloud STT loses its blue - you read the cloud icon instead. In exchange brand blue goes back to meaning "this is a control", and the row stops competing with the title.

Option D

Stage × locality matrix

Four states, four looks. STT local = matcha filled, STT cloud = neutral. LLM local = matcha outlined, LLM cloud = blueberry outlined. Every meeting row is visually unique; no two states ever collapse into the same pill.

Local · small.en llama3.1 Cloud · nova-3 MiniMax-M3

Cost: "matcha" stops meaning one thing - it now carries both "STT" and "local". Mental model becomes "matcha = stayed on this Mac; border = was processed by an LLM". Most expressive option, also the most to read.

Option E

One hue per stage, lightness for locality

Matcha family always means STT, blueberry family always means LLM. Filled = on this Mac, outlined = went to a provider. The brain reads "same stage" first because the two pills sit next to each other, then locality second.

Local · small.en Cloud · nova-3 llama3.1 MiniMax-M3

Cost: blueberry is back as the loud "AI" cue across the app, which is partly what option C was rebelling against. Wins on visual pairing between the two pills; loses on "blueberry = a control you can press".

Option F

Color = outcome

Matcha = ran cleanly (the normal case). Strawberry = needs attention (failed or never ran). Neutral = hasn't been processed yet. Locality comes from icon + label only. Best if you care more about "is my enhanced summary trustworthy?" than "did anything leave the Mac?".

Local · small.en Cloud · nova-3 MiniMax-M3 enhance failed

Cost: throws away the "local vs cloud" signal that the existing palette is built around - matcha no longer means "stayed on this Mac", it means "worked". Straw gets a new role too, so its current uses (recording dot, error toasts) need to be checked for collisions.

Option G

Matched-pair locality

When both pills agree on locality they share the same soft tint (two soft-matcha or two soft-blueberry). When they disagree, they split visually - one matcha, one neutral. Reads as "this meeting's two processes either agreed on staying local or they didn't." A new signal nothing else in the app produces.

Local · small.en llama3.1 Cloud · nova-3 MiniMax-M3 Local · small.en MiniMax-M3

Cost: the soft tints are new and have to read against the cream background - first version may need a contrast pass. Also adds a third color dimension (tint family) on top of the existing two, so onboarding a new user takes longer.
