Why this is mostly a token change

The app is built on Tailwind 4's CSS-first @theme in web/src/index.css. Every color, radius, shadow and font is a --color-*, --radius-*, --shadow-* or --font-* variable, and Tailwind emits var(--…) in every utility.

Dark mode (UI-6) already works by re-pointing color tokens under :root[data-theme="dark"], so components never hardcode palette hex. The same seam lands this restyle: change the values once and the 69 non-test components follow.

What does not follow for free is the set of call sites that reach past the tokens. The survey below lists them, and PR A migrates them first so the flip is complete.

Rollout: two PRs

PR A · UI-11a

Move off-token styles onto tokens

Pure refactor, zero intended visual change. Reviewable by diff; Playwright before/after should be pixel-identical.

  • 14 radius files → token utilities
  • 10 shadow literals → token utilities
  • 9 inline headings → heading-*
  • add --radius-panel, heading-greeting (34px), heading-title (30px)
PR B · UI-11b

Flip tokens to Whimsical × Blueberry

Small diff, whole-app visual change. PR body carries screenshots of the five routes in light and dark next to the mockups.

  • index.css token values and heading-* utilities
  • dark shadow overrides
  • Button sizing
  • font imports and package.json

Splitting keeps the visual review of PR B free of 30 mechanical edits, and PR A cannot regress anything visible. Both stay under web/, so both qualify for the cloud-session path in AGENTS.md.

Decisions needed from Richard

1

Blueberry glow on primary buttons

Whimsical is flat. Today's primary has a shadow-button-blue glow.

✓ Recommend: keep it, softened to 0 8px 16px -6px rgba(91,79,199,.35). The one place yogurt stays more playful than Whimsical.

Heading weight

Mock uses Manrope 800 everywhere. 700 reads calmer next to 15px body.

✓ Recommend: 800 for hero, greeting, title, section. 700 for card, sm, wordmark.
3

Body text size

Mock rendered at 14px. The app is 15px.

✓ Recommend: stay at 15px. Manrope is compact enough and nothing has to move.
4

Circles stay circles

22 rounded-full sites are dots, avatars and icon buttons.

✓ Recommend: confirm they are excluded from PR A so it does not over-migrate.
