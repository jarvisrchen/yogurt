# Release log

This is the record of every yogurt release: what shipped, which CI runs verified it, and what the smoke test found.
Every release appends a row here, as the last step of the [`release` skill](../.claude/skills/release/SKILL.md).
Notes are a bullet list, `<br>`-separated since a table cell cannot hold real lines: one PR-linked bullet per change, then the verification trail of CI runs and formula shas, plus anything the release taught us.
`scripts/release.sh finish` prints the row pre-filled.
