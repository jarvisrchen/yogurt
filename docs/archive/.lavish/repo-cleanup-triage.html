Go-public repo triage

Everything a public visitor would see, triaged with a recommendation preselected. Change any radio you disagree with, add notes at the bottom, then hit Queue decisions once and send. Nothing is deleted from git history by tree cleanup alone - that is what decision #1 is about.

The one decision that changes everything: the full internal history (all 200+ commits, every .planning doc, lavish HTML, design bundles) is already pushed to the private repo. Deleting files now only cleans the tree - history keeps everything forever. While the repo is still private we can rewrite main freely at zero cost.
