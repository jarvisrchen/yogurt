§ 01

Vision

Granola is the best meeting-notes UX shipped in years. Two ideas make it work:

  1. System-audio capture instead of a meeting bot. No "Granola AI has joined the call." Just turn it on and it hears everything.
  2. Augmented notes instead of summaries. Your bullets stay ink black; the LLM expands them in-place with grey additions. Editing a grey line promotes it to black. Every grey bullet links back to the transcript moment.

Granola is a commercial SaaS that streams your audio to Deepgram and your transcripts to OpenAI/Anthropic. Anyone under NDA, in compliance-bound roles, or who simply prefers local-first software has no comparable tool — the closest OSS projects (Meetily, Hyprnote) ship summaries, not augmented notes.

yogurt is that tool.

§ 02

Goals · non-goals · anti-goals

Goals v1
  • Granola-faithful augmented notes UX
  • Mic + system audio capture, no bot
  • Pluggable STT — cloud default, local fallback
  • BYO OpenAI-compatible LLM
  • Privacy-first — audio deleted after STT
  • brew install yogurt end-to-end
  • git clone && cargo run for devs
  • CLI-launched, browser UI only
Non-goals defer to v2+
  • Calendar integration
  • Re-enhance template picker + versions rail (confirmed v2)
  • Cross-meeting chat / search
  • Slack / Notion / CRM exports
  • Mobile / web-hosted
  • Multi-user / auth / sync
  • Per-speaker diarization
  • MCP server / external API
  • Windows / Linux
Anti-goals never
  • Joining meetings as a participant bot
  • Sending audio to a yogurt cloud (there is none)
  • Subscription billing or telemetry by default

Anti-goals are things we commit to never doing, even under pressure.

§ 05

v1 feature list (11 features)

Each with concrete acceptance criteria. Click any card to expand. §§5.9-5.11 added 2026-06-24 from the Claude Design board handoff.

5.1Record meeting (mic + system audio)›

Click "New meeting" → macOS Screen Recording permission prompt → captures two 16kHz mono PCM streams (mic + system loopback) pushed to STT via Tokio broadcast.

Done when: 30-min recording on macOS 13+ captures both channels cleanly; clean stop on "End meeting."
5.2Live transcript panel (right-edge dock)›

Collapsed by default as a right-edge tab labeled "Live transcript" with a 3-bar animated wave icon. Click expands — docks beside notes (330px wide), slides in from right at 340ms with cubic-bezier(.2,.7,.2,1). Notes stay fully editable while the panel is open. Channel labels: "Me" (ink) / "Them" (grey). Mono timestamps. Auto-scroll with pause-on-scroll-up.

Done when: < 2s lag with Deepgram, < 3s lag with local whisper.cpp small.en. Panel open/close animates cleanly without re-flowing notes.
5.3Augmented notes editor hero›

During the meeting: single markdown editor (TipTap), centered, max ~660px. Pure markdown. Lilac pill below reads "✨ AI enhances these when you hit End."

On End: editor enters enhancing state — progress bar + shimmer skeletons that resolve into grey markdown bullets, staggered (140/340/560/760ms — see §16 motion tokens).

Post-meeting view = one combined document. User bullets stay ink black, AI bullets grey under the same headings. Reads as one coherent doc.

Display contract
User content → ink black
AI content → grey
Diff is structural (markdown AST), not char-by-char.
Edit contract
Editing grey → promotes to black (it's "yours" now)
Black ranges never overwritten by re-enhance
Grey bullets carry data-transcript-ts for deep-links

Transcript deep-links: each AI bullet ends with ↳ HH:MM. Click → opens transcript panel + scrolls to timestamp.

Re-enhance button top-right ("Re-enhance"). v1: re-runs the same bundled enhance.md. No template picker, no versions rail — those are v2.

Done when: user types 5 sparse bullets in 30min meeting, hits End, sees clean enriched doc within 30s with black/grey contract intact and ↳ HH:MM links jumping the transcript correctly.
5.4In-meeting chat — "Ask this meeting…" (⌘K)›

Floating pill, anchored bottom-center of meeting view (480px wide, 24px from bottom). Reads "Ask this meeting…" placeholder + ⌘K hint. Click or ⌘K expands into chat window (260ms ease-out popUp animation). Notes stay live behind it — no dim.

System prompt from chat-system.md. Tuned for: "What's the current topic?", "Summarize the last 5 minutes.", "What did we decide on X?"

Done when: first chunk streams < 2s after sending; transcript references are accurate; pill/window animations feel snappy.
5.5Bundled prompts (internal, 2 files)›

crates/yogurt-prompts/ ships exactly two files in v1:

  • enhance.md — augmented-notes prompt (§5.3 depends on this)
  • chat-system.md — system prompt for in-meeting chat (§5.4)

Not user-facing templates. No picker, no per-meeting prompt switching. Power users edit either file; binary reload picks up changes.

✓
Template picker decision (closed 2026-06-24)
The design board's Re-enhance popover with Standup / Generic / 1:1 / Interview debrief templates and the v1/v2/v3 versions rail are deferred to v2 (see §6 item 2). v1 Re-enhance button simply re-runs enhance.md.
5.6Settings UI›

Two-column page: 212px section sidebar (Model · Transcription · Audio · General) + main content. Config in ~/.yogurt/config.toml; API keys in macOS Keychain.

Model: Active provider rendered as blueberry-bordered card (name + "Active" badge + Edit). Base URL / Model / API-key fields. Inactive providers stack below. "CLONE A PRESET" row with dashed Ollama / LM Studio / OpenRouter chips.

Transcription: side-by-side cards — Cloud (Deepgram / AssemblyAI / Groq, blueberry border when active) vs Local · whisper.cpp (matcha-soft, model picker tiny.en / small.en / medium.en / large-v3).

Audio + General stacked at bottom — input device dropdown, port, "Open browser on start" toggle.

5.7Local storage (SQLite + markdown export)›

SQLite at ~/.yogurt/db.sqlite + one markdown file per meeting at ~/.yogurt/notes/<ts>-<slug>.md. Markdown is canonical for "grep my meetings"; SQLite is the structured mirror. Schema in §9.

5.8macOS only (Apple Silicon primary)›

Universal binary (arm64 + x86_64). macOS 13+ required (ScreenCaptureKit). Intel best-effort — small.en only model that keeps real-time. Windows/Linux: out of scope; platform code lives behind crates/yogurt-audio trait so ports are additive.

5.9Meeting library — home view›

Default page at localhost:7878. 212px sidebar with yogurt swirl + wordmark, "+ New meeting" primary button, "All meetings"/"Starred" nav, Folders section with color dots (Work blue, Hiring strawberry, 1:1s matcha) + count, bottom "Local-only · on" matcha pill + ⚙ Settings.

Main: greeting in Instrument Serif ("Good afternoon, Dana"), search pill top-right, meeting list grouped by date (TODAY / YESTERDAY caption labels). Each card: 42px tinted-square avatar with initials in Serif, title (Hanken 700), meta line ("2:00 PM · 38 min · enhanced"), small badges on right.

Done when: user lands on library, sees meetings grouped by day, can click in / create new / "Local-only · on" pill reflects cloud-provider state.
5.10Onboarding (first-run, 3 steps)›

Route localhost:7878/welcome. Two-column on paper.

Left: yogurt logo, Serif welcome, one-liner, small terminal mockup:

$ yogurt start
✓ server live on :7878
✓ opening your browser…
→ waiting for screen-recording grant ▍

Right: "ONE-TIME SETUP" caption + 3-step vertical cards:

  1. Screen Recording — matcha "✓" once granted
  2. Connect your model — current step, blueberry border, provider chips (Minimax active, OpenAI/Ollama/OpenRouter as presets)
  3. Pick transcription — pending, "Cloud Deepgram or local whisper.cpp"

Primary button "Take me to my meetings →" (blueberry, full-width). Footer: "Restart once after granting — a macOS quirk, not us."

5.11Empty & error states›

Empty library: centered floating swirl logo (3.5s float animation), Serif "No meetings yet" headline, "Start your first meeting" CTA with ⌘N hint, mono caption "notes saved to ~/.yogurt/notes/*.md".

Permission not granted: full-screen warning. Strawberry-tinted ⚠ icon, Serif "yogurt can't hear the call yet" headline, numbered 3-step recovery (Open System Settings → Toggle yogurt on → Restart once), CTA pair: "Open System Settings" (primary) + "Restart Yogurt" (outline).

Enhancing state: lilac progress banner with pulse dot ("Weaving your notes into the transcript…"), animated bar, char-streaming count. Existing notes stay; new bullets appear as shimmer skeletons that resolve into grey text.

First-time whisper.cpp download: modal card. Matcha ↓ icon, "Downloading small.en" / mono caption "whisper.cpp · 487 MB", matcha progress bar with bytes/speed/ETA, "Most users stay on cloud STT and never see this." Button pair: Cancel / Run in background.

├── Cargo.toml                      # workspace root
├── crates/
│   ├── yogurt-cli/                 # binary entrypoint: `yogurt start`, `yogurt config`

Each crate independently testable, one clear purpose. Platform code behind a trait so Win/Linux ports are additive, not invasive.

§ 11

Distribution & dev workflow

✓
Yes — brew install yogurt installs everything as one command.
Single static Rust binary with web assets embedded (rust-embed), whisper.cpp linked statically, ScreenCaptureKit bindings against the system framework. Homebrew formula downloads the prebuilt binary for the user's arch. No Node, no Python, no separate audio helper.
End-user install
$ brew install yogurt
$ yogurt start
→ http://localhost:7878 opens in your browser
→ macOS prompts for Screen Recording permission
Source / contributor workflow
$ git clone github.com/<org>/yogurt.git
$ brew install rust pnpm
$ pnpm --dir web install
 
# terminal 1 — backend, auto-rebuild:
$ cargo run -p yogurt-cli -- start --dev
 
# terminal 2 — frontend HMR:
$ pnpm --dir web dev

§ 13

Open risks

⚠
screencapturekit crate gaps for audio-only loopback
Mitigation: Phase 2 spike. If crate falls short, ship a thin Swift binary (~150 lines) as subprocess. Pure additive change.
⚠
TipTap struggling with structural diff of LLM-rewritten markdown
Mitigation: Phase 4 prototype against 3 real meeting transcripts. Fallback: ProseMirror directly. This is the single highest-risk item.
·
whisper.cpp streaming partials worse than Deepgram
Mitigation: Acceptable — local is the privacy escape hatch. Document expected lag.
ⓘ
Browser getUserMedia permission collision
Non-issue: we don't use getUserMedia. All audio captured by the Rust binary; browser renders UI only.
⚠
First-meeting macOS Screen Recording permission friction
Mitigation: §5.11 permission-denied recovery screen with numbered steps + ⌘ to System Settings.
·
whisper.cpp model download size (500MB-3GB)
Mitigation: §5.11 model-download card with progress. Default cloud STT means most users never trigger it.
§ 14

Success criteria for v1

All four must be true for v1 to ship.

①
End-to-end install on M-series.
New user runs brew install yogurt && yogurt start, grants Screen Recording, pastes Minimax key, records + transcribes + gets augmented notes for a real meeting.
②
Black/grey notes feel indistinguishable from Granola.
Visual quality of the augmented-notes merge is the headline feature; if this isn't right, nothing else matters.
③
Fully-local mode works end-to-end.
Privacy-focused user can switch to whisper.cpp + a local Ollama endpoint; pipeline runs with no internet.
④
Dev environment in 5 minutes.
Developer can git clone && cargo run and have a working dev environment within 5 minutes from cold.
