Product requirements · v1 · 2026-06-24

Yogurt is the
local-first Granola
you launch from the CLI.

Single Rust binary. Browser UI at localhost:7878. Captures both your mic and your Mac's system audio without joining the call as a bot. Pluggable LLM via any OpenAI-compatible endpoint — Minimax, OpenAI, Ollama, OpenRouter, anything. Audio deleted after transcription. Notes stay on your machine.

§ 01

Vision

Granola is the best meeting-notes UX shipped in years. Two ideas make it work:

  1. System-audio capture instead of a meeting bot. No "Granola AI has joined the call." Just turn it on and it hears everything.
  2. Augmented notes instead of summaries. Your bullets stay black; the LLM expands them in-place with grey additions. Edit a grey line and it promotes to black. Every grey bullet links to the transcript moment it came from.

Granola is a commercial SaaS that streams your audio to Deepgram and your transcripts to OpenAI/Anthropic. Anyone under NDA, in compliance-bound roles, or who simply prefers local-first software has no comparable tool — the closest OSS projects (Meetily, Hyprnote) ship summaries, not augmented notes.

Yogurt is that tool.

§ 02

Goals, non-goals, anti-goals

Goalsv1
  • ✓ Faithfully reproduce Granola's augmented-notes UX
  • ✓ Capture mic + system audio on macOS without a bot
  • ✓ Pluggable transcription (cloud default, local fallback)
  • ✓ Any OpenAI-compatible LLM via Settings
  • ✓ Privacy-first defaults — audio deleted after STT
  • ✓ brew install yogurt for non-devs
  • ✓ git clone && cargo run for devs
  • ✓ Run entirely from CLI; no app bundle in v1
Non-goalsdefer to v2+
  • ✗ Calendar integration (Google / Outlook OAuth)
  • ✗ Cross-meeting chat or semantic search
  • ✗ Slack / Notion / CRM exports
  • ✗ Mobile / web-hosted version
  • ✗ Multi-user, auth, sync
  • ✗ Per-speaker diarization (beyond Me/Them)
  • ✗ MCP server / external API
  • ✗ Windows / Linux support
  • ✗ Custom-template authoring UI
Anti-goalsnever
  • ⊘ Joining meetings as a participant bot
  • ⊘ Sending audio to a Yogurt cloud (there is none)
  • ⊘ Subscription billing or telemetry by default
Anti-goals are the things we commit to never doing, even if pressured.

§ 05

v1 feature list (8 features)

Each with concrete acceptance criteria. Click any card to expand. cut: template picker / summary tab — 2026-06-24

5.1Record meeting (mic + system audio)

Click "New meeting" → macOS Screen Recording prompt → captures two 16kHz mono PCM streams (mic + system loopback) pushed to STT via Tokio broadcast.

Done when: 30-min recording on macOS 13+ captures both channels cleanly; clean stop on "End meeting."

5.2Live transcript panel

Right panel, scrolling, channel-labeled (Me = black, Them = grey), millisecond timestamps, auto-scroll with sticky behavior.

Done when: <2s lag with Deepgram, <3s lag with local whisper.cpp small.en.

5.3Augmented markdown notes editor signature feature

TipTap-based markdown editor on the left of the meeting view. Pure markdown during the meeting; on "End meeting" the LLM gets (notes + transcript + template) and returns enriched markdown.

Display contract
  • · User content → black
  • · AI-added content → muted grey
  • · Diff is computed structurally (markdown AST), not char-by-char
Edit contract
  • · Editing a grey range → promotes to black
  • · Black ranges → never overwritten on re-enhance
  • · Grey bullets carry data-transcript-ts; click jumps transcript

Done when: user types 5 sparse bullets in 30min meeting, hits End, sees enriched doc within 30s with black/grey contract intact and grey-bullet clicks jumping the transcript.

5.4In-meeting AI chat

Collapsible right panel. System prompt: "You are watching this meeting live. Answer using only the transcript so far." Streams response inline.

Tuned for: "What's the current topic?", "Summarize the last 5 minutes.", "What did X say about Y?"

Done when: first chunk <2s after send, references transcript content accurately.

5.5Bundled prompts internal · 2 files

crates/yogurt-prompts/ ships exactly two prompts in v1:

  • · enhance.md — produces the black/grey merged notes (5.3 depends on it)
  • · chat-system.md — system prompt for in-meeting chat (5.4)

Not "templates" in the user-facing sense — no picker, no summary tab, no per-meeting switching. Power users edit either file in the repo; binary reload picks up changes.

Why no picker? Brainstorm decision (2026-06-24). Based on user's own experience that they never used the Granola template picker. Cutting it removes UI surface, a DB table (summaries), an API endpoint (/summarize), and an entire roadmap phase. Template picker defers to v2 — see §06.
5.6Settings UI

Page at /settings, config in ~/.yogurt/config.toml.

  • LLM: list of providers (name + base URL + key + default model). Presets for Minimax / OpenAI / Ollama / LM Studio / OpenRouter.
  • STT: Cloud (Deepgram | AssemblyAI | Groq Whisper) or Local (whisper.cpp with model picker).
  • Audio: input device picker.
  • General: port, data dir, auto-open browser.

API keys → macOS Keychain via keyring crate, never in plaintext.

5.7Local storage (SQLite + markdown export)

SQLite at ~/.yogurt/db.sqlite + one markdown file per meeting at ~/.yogurt/notes/<ts>-<slug>.md.

Markdown is the source of truth for "I want to grep my meetings"; SQLite is the structured mirror.

5.8macOS only (Apple Silicon primary)

Universal binary (arm64 + x86_64). macOS 13+ required (ScreenCaptureKit). Intel is best-effort. Architecture isolates platform code in crates/yogurt-audio so future Win/Linux is additive.

§ 11

Distribution & dev workflow

Yes — brew install yogurt installs everything as one command.

Single static Rust binary. Web assets embedded via rust-embed, whisper.cpp linked statically, ScreenCaptureKit bindings against the system framework. The Homebrew formula downloads the prebuilt binary for the user's arch from the matching GitHub Release and drops it in /opt/homebrew/bin/yogurt. No Node, no Python, no separate audio helper.

End user install
brew install yogurt
yogurt start
→ opens http://localhost:7878
→ macOS prompts for Screen Recording permission
Alternative installs
 Rust developers:
cargo install yogurt
 
 Direct binary download:
curl -L github.com/<org>/yogurt/releases/latest/...
Source / contributor workflow
git clone https://github.com/<org>/yogurt.git
cd yogurt
brew install rust pnpm
pnpm --dir web install
 
 terminal 1 — backend with auto-rebuild:
cargo run -p yogurt-cli -- start --dev
 
 terminal 2 — frontend HMR:
pnpm --dir web dev
 
 release build (single binary):
pnpm --dir web build && cargo build --release

Release pipeline (GitHub Actions, on tag v*)

  1. Matrix build: aarch64-apple-darwin + x86_64-apple-darwin
  2. Each builds frontend → cargo build --release
  3. Tarballs uploaded to GitHub Release
  4. Workflow opens PR against homebrew-yogurt tap w/ updated SHA256
  5. cargo publish for the binary crate

§ 13

Open risks

screencapturekit crate gaps for audio-only loopback

Mitigation: Phase 1 spike. If crate falls short, ship a thin Swift binary (~150 lines) as a subprocess. Pure additive change, no architectural reshape.

TipTap struggling with structural diff of LLM-rewritten markdown

Mitigation: Phase 3 prototype against 3 real meeting transcripts before committing. Fallback: ProseMirror directly. This is the single highest-risk item.

whisper.cpp streaming partials worse than Deepgram

Mitigation: Acceptable — local is the privacy escape hatch, not daily-driver. Document expected lag.

Browser getUserMedia permission collision

Mitigation: Non-issue — we don't use getUserMedia. All audio captured by the Rust binary; browser only renders UI.

First-meeting macOS Screen Recording permission friction

Mitigation: Onboarding screen with screenshot explaining the prompt. After grant, user must restart Yogurt once (macOS limitation, not ours).

whisper.cpp model download size (500MB-3GB)

Mitigation: Settings shows download progress. Default cloud STT means most users never trigger it.

§ 14

Success criteria for v1

All four must be true for v1 to ship.

①
End-to-end install on M-series.
New user runs brew install yogurt && yogurt start, grants Screen Recording, pastes Minimax key, records + transcribes + gets augmented notes for a real meeting.
②
Black/grey notes feel indistinguishable from Granola.
Visual quality of the augmented-notes merge is the headline feature; if this isn't right, nothing else matters.
③
Fully-local mode works end-to-end.
Privacy-focused user can switch to whisper.cpp + a local Ollama endpoint and the pipeline runs with no internet.
④
Dev environment in 5 minutes.
Developer can git clone && cargo run and have a working dev environment within 5 minutes from cold.
