The hero flow was broken end to end. Now it is real.

wasThe live transcript was never persisted anywhere. The browser sent a hardcoded [] to enhance, so the AI notes, chat answers, transcript panel, and search all ran against an empty transcript in every real meeting.
fixedThe server now accumulates final STT segments into the meeting row while recording and flushes on stop. Enhance and chat read the stored transcript. Deep links, the post-meeting transcript panel, and grounded chat all work.
wasChat always answered from a hardcoded mock LLM. Your configured provider was never called once - the source of every "No response." bubble.
fixedChat and enhance share one per-request resolver: env override, then the active provider + Keychain key, mock only when nothing is configured. Verified live against Minimax: asked the pricing meeting a question, got the grounded answer.
wasStopping a meeting leaked the STT session forever - Deepgram kept its socket open and local whisper pinned a multi-GB model, decoding every second. Timestamps were never stamped, so every meeting showed a dash duration.
fixedSTT lifetime is tied to the meeting (abort guards), start/stop stamp the timestamps, and a tri-state bug that let enhance erase ended_at is gone. The library now shows "9:06 PM · 2 min · enhanced".
wasNotes lived only in React state (navigate away, lose everything), and during validation the new post view was caught wiping a real enhanced document with a blank unmount flush.
fixedDebounced autosave for notes and enhanced content, gated so only genuine user edits persist, plus a server-side guard that refuses to blank a non-empty document. Both layers carry regression tests reproducing the observed wipe.
wasRelease builds had no way to enter a Deepgram key (env var only), so cloud transcription - the default - could never work for a real install.
fixedThe key lives in the macOS Keychain with a Settings field and endpoint; dev still seeds from .env.local. Every Keychain read is now bounded with an actionable error instead of hanging (one wedged read used to stall boot for half an hour).
