your question

"For Q8 option A, would brew install yogurt just do install for everything? I also want an option to be able to clone the repo and run locally."

answer (also documented in PRD §11)

Yes — one command. Because we picked Rust + embedded web assets + statically linked whisper.cpp, the entire app is a single static binary. The Homebrew formula downloads the pre-built binary from the matching GitHub Release for the user's architecture and drops it in /opt/homebrew/bin/yogurt. No Node, no Python, no separate audio helper. 

brew install yogurt
yogurt start
→ http://localhost:7878 opens in your browser

Clone + run locally is fully supported and documented as a first-class path. Two terminals during dev (Vite hot-reloads the frontend, Cargo runs the backend); one binary for release. 

git clone https://github.com/<org>/yogurt.git && cd yogurt
brew install rust pnpm
pnpm --dir web install
 
 terminal 1 — backend, auto-rebuilds on save:
cargo run -p yogurt-cli -- start --dev
 terminal 2 — frontend, HMR:
pnpm --dir web dev
 
 release build (single binary):
pnpm --dir web build && cargo build --release

Q6 LLM provider OpenAI-compatible only. Ships with presets for Minimax, OpenAI, Ollama, LM Studio, OpenRouter
Q7 Audio retention Delete audio after transcription (Granola model). Per-meeting keep-toggle deferred to v1.1
Q8 Distribution Homebrew + Cargo + GitHub Release binaries. Source build (clone + cargo run) first-class
