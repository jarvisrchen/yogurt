## AVAuthorizationStatus → PermissionStatus Mapping (shipped)

```
AVAuthorizationStatus::Authorized    (3) → PermissionStatus::Granted
AVAuthorizationStatus::Denied        (2) → PermissionStatus::Denied
AVAuthorizationStatus::Restricted    (1) → PermissionStatus::Denied
AVAuthorizationStatus::NotDetermined (0) → PermissionStatus::NotDetermined
_  (any future variant)                  → PermissionStatus::Denied  (safe default)
```

The function is implemented in `crates/yogurt-audio/src/permission.rs`
inside `macos::map_av_status()`, using the named `AVAuthorizationStatus`
constants from `objc2-av-foundation` rather than literal integers — same
mapping, but the intent is self-documenting and survives any unlikely
future AVFoundation re-numbering. The wildcard arm makes the match
exhaustive (the binding uses an `NSInteger` newtype, not a `#[non_exhaustive]`
enum, so the compiler cannot enforce exhaustiveness on its own).

## Deviations from DD-01..DD-07

### DD-01 — `block2` version bump

**Stated:** "add `block2 = "0.5"` as a macOS-only dep if needed".
**Shipped:** `block2 = "0.6"`.
**Justification:** DD-01 also instructed "pin the latest released versions
reachable via `cargo search`". `cargo search block2` returns `0.6.2` as
the latest, and `objc2-av-foundation 0.3.2` (the version DD-01 selected)
transitively pulls in `block2 0.6` via its `block2` feature — selecting
`0.5` would cause a duplicate `block2` major-version resolution conflict
and fail to build. The 0.6 pin satisfies the spirit of DD-01 (use the
maintained current release) and the letter of the "pin latest" rule.

### DD-06 — confirmed (no deviation)

`start_capture()` was not modified; the screen-recording-permission gate
inside `start_capture` is unchanged. cpal still fails fast on mic denial
as the safety net; the Welcome CTA gate is the user-facing protection.

### DD-07 — confirmed (no deviation)

No Info.plist work; no .app bundle plumbing. macOS will use the parent
terminal's TCC entry (or fall back to the CLI binary's bundle id) for
the system dialog. The dialog text will be macOS-generic
("yogurt would like to access the microphone") for v1.

### All other DDs (02, 03, 04, 05) — implemented verbatim

No deviations.
