(2) Create `web/src/lib/ws.ts` per superpowers Step 2:
  - Export type `Channel = "mic" | "system"` and interface `TranscriptEvent { ts_ms, channel, text, is_final }` (snake_case fields, matches server payload).
  - Export `useTranscriptWs(meetingId: string | null): { events: TranscriptEvent[]; connected: boolean }`.
  - Inside: `useEffect` opens `new WebSocket(${proto}//${window.location.host}/ws/meetings/${meetingId})` where proto is `wss:` on https else `ws:`.
  - `onopen` → `setConnected(true)`; `onclose` → `setConnected(false)`; `onmessage` parses JSON, checks `frame.type === "transcript"`, calls `setEvents(prev => mergeEvent(prev, frame.payload))`.
  - `mergeEvent` strategy: if new event `is_final` → push. Otherwise find last event on same channel; if last is non-final, REPLACE it; else push. Result: stable list of finals with at most one trailing partial per channel.
  - Cleanup: `ws.close()` in useEffect return.

(3) Create `web/src/lib/ws.test.ts` per superpowers Step 3:
  - Mock `WebSocket` globally via `vi.stubGlobal` with a `MockWebSocket` class that auto-fires `onopen` on next microtask and exposes `emit(data)` to trigger `onmessage`.
  - Test 1 (`merges a partial then a final into the events list`): emit two partials (`"hel"` → `"hello"`) and assert events.length stays 1; emit a final and assert length still 1 but `is_final === true` and `text === "hello world"`.
  - Test 2 (`keeps mic and system partials independent`): emit one mic partial + one system partial, assert events.length === 2.
  - Use `@testing-library/react`'s `renderHook` + `act`.
