Key invariants:
  - `pub struct DeepgramStt { pub api_key: String, pub base_url: String, pub model: String }` — `base_url` MUST be `pub` so tests can override to `ws://127.0.0.1:<port>`.
  - `DeepgramStt::new(api_key)` defaults `base_url` to `"wss://api.deepgram.com"` and `model` to `"nova-2"`.
  - `connect_url()` produces: `{base}/v1/listen?model={model}&encoding=linear16&sample_rate=16000&channels=1&interim_results=true&endpointing=300&smart_format=true`.
  - `impl Stt for DeepgramStt::start` opens TWO sessions via `spawn_session(self, Channel::Mic, txn.clone())` and `spawn_session(self, Channel::System, txn.clone())`, then pumps the unified `audio_rx` into the per-channel `mpsc::Sender<AudioChunk>` based on `chunk.channel`. Lagged → warn + continue. Closed → break + drop senders so writer tasks send `CloseStream` and exit.
  - `spawn_session()` builds the request with `Authorization: Token <api_key>` header, opens via `tokio_tungstenite::connect_async`, splits into writer + reader tasks:
    - Writer: drain mpsc → `Message::Binary(i16_slice_to_le_bytes(&samples))`. On channel close: send `{"type": "CloseStream"}` text frame then `write.close()`.
    - Reader: WS text frames → `parse_deepgram_event(&text, channel)` → `txn.send(ev)` (ignore lagged subscribers). Close frame → return.
  - `parse_deepgram_event()` ignores frames where `type != "Results"` or `transcript` is empty/whitespace; converts `start` (f64 seconds) to `ts_ms: u64` via `(start_s * 1000.0) as u64`; reads `is_final` (defaulting to false).
  - `i16_slice_to_le_bytes()` writes little-endian via `s.to_le_bytes()`.
  - Inline `#[cfg(test)] mod tests` with all four tests from superpowers Step 1: `it_parses_a_final_results_frame`, `it_ignores_empty_transcripts`, `it_ignores_metadata_frames`, `it_converts_i16_to_le_bytes_correctly`.

  3. Constructs broadcast channels `(audio_tx, audio_rx)` and `(txn_tx, txn_rx)`.
