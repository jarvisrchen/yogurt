Step 3: Create `web/src/hooks/useChat.ts`:
- Signature: `useChat(meetingId: string) => { messages: ChatMessage[]; send: (content: string) => Promise<void>; streamingId: string | null; error: string | null }`.
- On mount + meeting change, call `fetchChatHistory(meetingId)` and seed `messages`; handle cancellation via a `cancelled` flag.
- Subscribe to `"chat_chunk"` via the Phase 3 socket hook. Handler appends `ev.delta` to the matching message (find by id) or creates a stub if none found yet. When `ev.done && streamingIdRef.current === ev.message_id`, clear `streamingId`.
- Use a `streamingIdRef` (useRef) to track the latest streamingId without stale-closure issues in the subscribe callback.
- `send(content)` — push optimistic user bubble (`id: tmp-${Date.now()}`), call `postChatMessage`, set `streamingId` to returned `message_id`, pre-create an empty assistant bubble with that id so chunks have a target. On POST failure, roll back the optimistic user bubble.
