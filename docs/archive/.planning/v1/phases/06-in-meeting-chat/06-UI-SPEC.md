## Motion

| Token | Value | Usage |
|-------|-------|-------|
| `popUp` | **260ms ease-out** | Pill → chat-window expansion. Hand-rolled CSS `@keyframes popUp` (NOT Framer Motion). Composite transform: scale `0.96 → 1`, translateY `8px → 0`, opacity `0 → 1`. Load-bearing from PRD §16.5 + CONTEXT D-05. |
| streaming-caret | ~1000ms (Tailwind `animate-pulse`) | Pulsing 6px × 14px block inside the streaming assistant bubble while `streamingId === message.id`. Intensity at Claude's discretion; the only requirement is "visibly pulses". |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **Send** (right-side circular button on the pill, lucide `Send` arrow icon; activates on `Enter` key in the pill input) |
| Secondary CTA | *(none — the collapse caret in the chat-window header returns to the floating pill; there is no "Cancel" or "Reset")* |
| Pill placeholder | "Ask this meeting…" (one-line, `--mut` color, no period after the ellipsis other than the single `…` glyph) |
| Keyboard hint badge | `⌘K` (rendered in JetBrains Mono inside a `--blsoft` chip; **macOS only — never substitute `Ctrl+K`**, see Registry Safety) |
| Chat window header | "Ask the meeting" (Instrument Serif, paired with the yogurt swirl logo on the left and the collapse caret on the right) |
| Empty state heading | "Ask the meeting" *(the window header doubles as the heading — there is no separate empty-state H1)* |
| Empty state body | "Ask anything about what's been said so far." (italic, `--mut`, centered in the messages area when `messages.length === 0`) |
| Error state | "Couldn't reach the model — check Settings → Model." (rendered as an inline notice; the pill **preserves the user's input** so they can retry without retyping; on stream error mid-response, a `[stream error: <message>]` chunk is appended to the in-flight assistant bubble per CONTEXT D-16) |
| Destructive confirmation | *(none in this phase — no delete affordance for chat messages in v1; see Deferred CONTEXT)* |

**Custom components introduced in this phase (no registry — owned in `web/src/components/`):**

| Component | Path | Responsibility |
|-----------|------|----------------|
| `AskPill` | `web/src/components/AskPill.tsx` | Collapsed floating pill: 480px wide, `⌘K` badge, send-arrow button, "Ask this meeting…" placeholder |
| `ChatWindow` | `web/src/components/ChatWindow.tsx` | Expanded chat surface: header (swirl + "Ask the meeting" + collapse caret), scrollable messages list, sticky input row at the bottom |
| `ChatMessage` | `web/src/components/ChatMessage.tsx` | Single message bubble (user vs. assistant variant); renders streaming caret when `streamingId === message.id` |
| `AskExperience` | `web/src/components/AskExperience.tsx` | Wrapper that toggles between `<AskPill />` and `<ChatWindow />`; mounted at the route root on both `Meeting.tsx` and `MeetingPost.tsx` |
| `useKeyboardShortcut` | `web/src/hooks/useKeyboardShortcut.ts` | Generic reusable hook bound for this phase to `{ key: "k", meta: true }` to trigger expansion |
| `useChat` | `web/src/hooks/useChat.ts` | Owns send + stream subscription + persistence; consumes the existing Phase 3 `useMeetingSocket(meetingId)` |

**Platform-specific copy rule:** Yogurt is **macOS-only** (PRD §1 + ScreenCaptureKit constraint). The keyboard-hint badge therefore renders **`⌘K`** exclusively — there is **no** `Ctrl+K` variant, no platform sniffing, no conditional rendering. The `useKeyboardShortcut` hook should still listen for `metaKey` only (not `ctrlKey`) so that Ctrl+K does not accidentally trigger expansion on a connected non-Apple keyboard.

**Sticky-no-outside-click rule:** The expanded chat window does **not** register an outside-click listener. Only the in-header collapse caret returns to the floating pill. This is intentional per PRD §5.4 and is asserted explicitly in `ChatWindow.test.tsx` — do not add a "click outside to dismiss" handler in a future refactor.
