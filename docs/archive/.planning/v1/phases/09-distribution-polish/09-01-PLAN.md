  <name>Task 3: Write `.github/workflows/release.yml` — matrix build + codesign + notarize + GitHub Release upload</name>
  <files>.github/workflows/release.yml</files>
  <read_first>docs/superpowers/plans/2026-06-25-yogurt-phase-9-polish-and-distribution.md</read_first>
  <action>
    Create `.github/workflows/release.yml`. Triggers: `push: tags: ["v*"]` AND `workflow_dispatch` with a `dry-run: boolean default true` input.

    Two jobs in this plan (Plan 09-02 adds `tap` and `publish`):

    **Job `build` (matrix):**
    - `strategy.matrix.target: [aarch64-apple-darwin, x86_64-apple-darwin]`, `fail-fast: false`
    - Runs on `macos-latest`
    - Steps: checkout → install Rust 1.83 with target → Swatinem cache (key `release-${{ matrix.target }}`) → pnpm setup v9 → setup-node 20 with pnpm cache → `pnpm --dir web install --frozen-lockfile && pnpm --dir web build` → `cargo build --release --target ${{ matrix.target }} -p yogurt` → strip binary → **codesign step** → **notarize step** → **staple step** → tarball + SHA256 → upload-artifact.
    - **Codesign:** import `APPLE_SIGNING_CERT_BASE64` into a temporary keychain (use `security create-keychain` + `security import` pattern); run `codesign --force --options runtime --sign "$APPLE_DEVELOPER_ID" --identifier ai.yogurt.app --timestamp target/${{ matrix.target }}/release/yogurt`. Bundle ID is passed via `--identifier ai.yogurt.app` (DIST-04).
    - **Notarize:** zip the signed binary, then `xcrun notarytool submit yogurt-signed.zip --apple-id "$APPLE_ID_EMAIL" --password "$APPLE_NOTARIZATION_PASSWORD" --team-id "$APPLE_TEAM_ID" --wait`. Exit non-zero if not Accepted.
    - **Staple:** `xcrun stapler staple target/${{ matrix.target }}/release/yogurt` (stapler attaches the ticket so Gatekeeper accepts offline).
    - **Verify:** `spctl -a -vv -t install target/${{ matrix.target }}/release/yogurt` MUST print "accepted". Fail the job otherwise.
    - **Tarball:** `tar -czf "yogurt-${{ matrix.target }}.tar.gz" -C target/${{ matrix.target }}/release yogurt` then `shasum -a 256 ... > ....sha256`.
    - **Upload:** `actions/upload-artifact@v4`, name `yogurt-${{ matrix.target }}`, paths `*.tar.gz` and `*.tar.gz.sha256`.

    **Job `release` (needs: build):**
    - Runs on `ubuntu-latest`, `permissions: contents: write`
    - Steps: checkout → download all `yogurt-*` artifacts → concatenate `*.sha256` files into `SHA256SUMS` → resolve version from `${GITHUB_REF#refs/tags/v}` (or `0.0.99-rc-dryrun-<ts>` for dry-run) → `softprops/action-gh-release@v2` ONLY if `github.event_name == 'push' || inputs.dry-run == false`. Uploads both tarballs + SHA256SUMS to a new GitHub Release tagged `${{ github.ref_name }}`, body from `./CHANGELOG.md`.
    - On dry-run: print "DRY RUN — would upload..." and `ls -la` the files, but do NOT create a release.

    Use the env vars from `secrets`: `APPLE_DEVELOPER_ID`, `APPLE_TEAM_ID`, `APPLE_NOTARIZATION_PASSWORD`, `APPLE_ID_EMAIL`, `APPLE_SIGNING_CERT_BASE64`, `APPLE_SIGNING_CERT_PASSWORD`.

    IMPORTANT: This plan does NOT add the `tap` or `publish` jobs — those are Plan 09-02's responsibility. Keep the workflow extensible (don't bake assumptions that make 09-02 hard).
  </action>
  <verify>`gh workflow view release.yml` (after pushing) lists the workflow. Trigger a dry-run via `gh workflow run release.yml -f dry-run=true && gh run watch` — both matrix builds must complete green and produce uploaded artifacts.</verify>
