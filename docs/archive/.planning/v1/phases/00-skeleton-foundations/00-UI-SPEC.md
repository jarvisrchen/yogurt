# Phase 0 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

> **READER WARNING — Phase 0 ships an unstyled scaffold.** The placeholder values in every table below exist only to prove the React + Vite + Tailwind + TipTap toolchain is wired end-to-end. They are **not** the Yogurt design system. The real design contract — brand tokens, typography, components, and copy voice — lands in **Phase 1 (Design System & Brand Tokens)**, which fully replaces every placeholder declared here. Do not cite this document as authoritative for visual decisions in Phase 2+.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FBF7EF` (hardcoded in `web/src/index.css` body background) | Page background |
| Secondary (30%) | `#FFFFFF` (Tailwind `bg-white`) | TipTap editor card surface |
| Accent (10%) | `#A3A3A3` (Tailwind `text-neutral-500`) + `#F5F5F5` (Tailwind `bg-neutral-100`) | Subtitle text + inline code chip |
| Destructive | not used in Phase 0 | — |

Accent reserved for: subtitle line under the "yogurt" headline and the inline `<code>` chip showing health status. **No interactive accent in Phase 0** — there are no buttons, links, or interactive controls beyond the TipTap editor body.

> **The `#FBF7EF` (paper-ish) and `#211D18` (ink-ish) values hardcoded in `web/src/index.css` are throwaway placeholders.** Phase 1 replaces them with the full paper / ink / grey / blueberry / strawberry / matcha token system per PRD §16.2, exposed through Tailwind 4's `@theme` block. Do not import `yogurt-app-design/` assets or treat these hex values as brand colors.
