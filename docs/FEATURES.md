## Internal routes

Routes with no user-facing feature of their own - infrastructure the app needs to boot or fail cleanly, not something a user or agent picks off a menu.

- `/api/health` - unauthenticated liveness probe; the SPA and `yogurt ctl` poll it, but there is no "health" screen.
- `/api/session-token` - bootstrap endpoint the SPA calls once on boot to learn the auth token used by every other call.
- `/api/:rest` - honest JSON 404 for any unmatched `/api/*` path (normalized from the extracted `/api/{*rest}` route).
- `/settings` - bare redirect to `/settings/model`.
- `*` - the React Router catch-all; redirects an unknown path to `/`.
