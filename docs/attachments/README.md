# Attachments

Screenshots, photos, and other visual evidence referenced from `../TODO.md`.

## Naming

Use `YYYY-MM-DD-<short-description>.<ext>` so files sort chronologically.

Examples:
- `2026-08-28-settings-modal-cutoff.png`
- `2026-08-29-chat-bubble-misaligned.png`

## Workflow

When the user sends a photo, save it here with a descriptive slug.
Then add a TODO entry to `../TODO.md` that references it inline.
