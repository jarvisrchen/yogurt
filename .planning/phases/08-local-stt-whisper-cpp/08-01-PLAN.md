Create `crates/yogurt-stt/src/whisper_local.rs` per source plan Task 8.6 with these guarantees:

1. `pub struct WhisperLocal { model_path: PathBuf, ctx: Arc<WhisperContext> }` — context is `Arc`'d because all decode paths share it.
2. `pub fn load(model_path: PathBuf) -> Result<Self>` — constructs `WhisperContext::new_with_params(...)`. NOTE: This is a blocking call. In `meetings/start.rs` (Plan 03) the CALLER wraps `load()` in `spawn_blocking`. Inside this fn we just synchronously load; document in a doc comment that callers MUST wrap.
3. Decode function: `fn decode(ctx: &WhisperContext, pcm_i16: &[i16], fast: bool) -> Result<String>` —
   - Convert i16 PCM → f32 via `whisper_rs::convert_integer_to_float_audio`.
   - Create `state = ctx.create_state()?`.
   - If `fast`: `FullParams::new(SamplingStrategy::Greedy { best_of: 1 })` (preview state).
   - Else: `FullParams::new(SamplingStrategy::BeamSearch { beam_size: 5, patience: 1.0 })` (settled state).
   - Set `params.set_language(Some("en"))`, disable all print flags, `set_no_context(fast)`.
   - Run `state.full(params, &f32_buf)`, collect segments into joined string.
4. `impl Stt for WhisperLocal { async fn start(...) }` —
   - Spawn two `mpsc::channel`'s (mic_seg / sys_seg), each draining into a worker `tokio::spawn` task.
   - Each worker task: `let text = tokio::task::spawn_blocking(move || Self::decode(&ctx, &pcm, false)).await...` — Final emits.
   - Spawn a third task: 1-second `tokio::time::interval` ticker that snapshots a rolling 5 s mic buffer, calls `spawn_blocking(... Self::decode(&ctx, &snapshot, true))`, emits Partial.
   - Main loop pumps `audio_rx.recv()` → segmenter `push` (segmenter is from Plan 02 `vad.rs`; for Plan 01 use a TODO stub or feature-flag the import; preferred: implement the loop body but mark VAD usage with `#[cfg(feature = "local-stt")]` so Plan 02 can land vad.rs cleanly).
   - Handle `RecvError::Lagged(n)` → log warn + continue; `RecvError::Closed` → break.
