<objective>
Land the two algorithmic core pieces of local STT: (1) the VAD-driven sliding-window segmenter that turns 16 kHz mono PCM streams into utterance-bounded Segments, and (2) the model download manager with SHA256 verification + Range-header resume. Both are TDD-first.

Purpose: These are the most error-prone components — VAD tuning constants drift, download resume has historically been a `Range:` minefield, and a wrong SHA256 hash breaks the feature 100%. Tests-first protects against the regressions that would otherwise only show up at user-facing acceptance time.
Output: Two new modules under `crates/yogurt-stt/src/` (`vad.rs`, `models.rs`) wired into `lib.rs` behind the `local-stt` feature, with two integration test files proving the contracts.
</objective>

Step 3 (impl): Append to `crates/yogurt-stt/src/models.rs`:
- `pub struct DownloadProgress { bytes_downloaded: u64, total_bytes: u64, bytes_per_sec: u64, eta_seconds: Option<u64> }` (Serialize + Deserialize + Clone).
- `pub enum DownloadError` (thiserror) — `Http(reqwest::Error)`, `Io(std::io::Error)`, `HashMismatch { expected, actual }`, `Cancelled`.
- `pub async fn download_to<F>(url: &str, dest: &Path, expected_sha256: &str, mut on_progress: F) -> Result<(), DownloadError>` where `F: FnMut(DownloadProgress) + Send + 'static`:
  1. Fast-path: if `dest.exists()` AND `hash_file(dest) == expected_sha256`, return Ok(()).
  2. Else: detect existing partial via `std::fs::metadata(dest).map(|m| m.len()).unwrap_or(0)`.
  3. Build `reqwest::Client` with `.user_agent("yogurt-stt/0.1")`.
  4. If existing > 0: add `Range: bytes={existing}-` header.
  5. Send; check `error_for_status()`; detect `status == PARTIAL_CONTENT` for resumed.
  6. Open file: `OpenOptions::new().append(true).open(dest)?` + seek to end if resumed; else `File::create(dest)`.
  7. Loop `resp.bytes_stream()` chunks; write each; update `downloaded` + `bytes_since_tick`; every ≥500 ms compute rate + ETA and fire `on_progress`. Final tick at 100%.
  8. `file.sync_all()?`; drop.
  9. `hash_file(dest)` — if mismatch, `std::fs::remove_file(dest)` + return `HashMismatch`.
- `pub async fn download<F>(spec: &ModelSpec, on_progress: F)` convenience that resolves `model_path` + calls `download_to`.
